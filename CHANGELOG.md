# Changelog

## [1.0.0] - 2026-10-10
* Initial production release of FaceVoiceID.
* Added face recognition engine via `face_recognition` and OpenCV.
* Added voice speaker verification engine using Librosa MFCCs.
* Added FastAPI web service wrapper, CLI workflows, and Streamlit user portal.
* Added containerization, Kubernetes deployment manifests, and automated testing suite.
